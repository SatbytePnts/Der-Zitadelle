# Что будет измененно:

• Разрешить запуск только .docx .excel

• Блокировать чтение/запись внешних носителей

• Отключить AutoPlay

• Блокировать весь исходящий/входящий трафик (интернет)

• Отключить PowerShell-скрипты и включить Constrained Language

• Включить Controlled Folder Access (Defender)

• Отключить макросы в Office

• Включить аудит процессов и объектов

# Как это работает

AppLocker:

      Разрешаем только хэш dcox.exe, по остальному — дефолтный Deny.
      Требуется служба Application Identity.

Removable Storage & AutoPlay:

        Через реестр запрещаем чтение/запись флешек.
        Отключаем автозапуск.

Firewall:

        Блокируем весь исходящий и (опционально) входящий трафик во все профили.
  
PowerShell:

        Жёсткий ExecutionPolicy + режим Constrained Language.
  
Exploit Guard:

        Включаем Controlled Folder Access из Defender.

Office:

        Ставим жесткий запрет на макросы во всех основных приложениях.

Аудит:

        Включаем логирование запуска процессов и доступа к ФС/реестру.
