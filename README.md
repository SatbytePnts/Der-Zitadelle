# Что будет измененно:

• Инструкция по настройке SRP

• Блокировать чтение/запись внешних носителей

• Отключить AutoPlay

• Блокировать весь исходящий/входящий трафик (интернет)

• Отключить PowerShell-скрипты и cmd для обычных пользователей (Имя передаёться внутри скрипта)

• Отключить макросы в Office

• Включить аудит процессов и объектов

• Создание безопасной локальной парольной политики

# Как это работает

SPR:
Настройка SRP (Software Restriction Policies)

    Откройте редактор локальной групповой политики:

        Нажмите Win + R, введите gpedit.msc и нажмите Enter.

    Перейдите к разделу SRP:

        В дереве слева выберите:
        Конфигурация пользователя → Политики → Конфигурация Windows → Параметры безопасности → Политики ограничения использования программ.

    Создайте политики ограничения:

        Если политики не настроены, щелкните правой кнопкой мыши на Политики ограничения использования программ и выберите Создать политики ограничения использования программ.

    Настройте уровень безопасности:

        В правой панели дважды щелкните Уровень безопасности.

        Выберите:

            Ограничено — запрещает запуск всех программ, кроме явно разрешенных.

            Не ограничено (по умолчанию) — разрешает запуск всех программ.

    Добавьте правила:

        Щелкните правой кнопкой на Дополнительные правила и создайте нужные правила:

            Путь — например, запрет запуска программ из папки C:\Temp.

            Хэш — блокировка по хэшу файла.

            Зона — ограничение программ из интернета (например, зона «Интернет»).

            Сертификат — разрешение по цифровой подписи.

    Примените политику:

        Закройте редактор групповой политики.

        Откройте командную строку с правами администратора и выполните:
        cmd

       gpupdate /force

Removable Storage & AutoPlay:

        Через реестр запрещаем чтение/запись флешек.
        Отключаем автозапуск.

Firewall:

        Блокируем весь исходящий и (опционально) входящий трафик во все профили.
  
PowerShell:

        Через реестр запрещаем запуск Powershell и cmd выбранному пользователю.
    необходимо заменить # Замените "Username" на имя нужного пользователя
    $user = "Username"
    в скрипте ps_cmd_disable.ps1
  

Office:

        Ставим жесткий запрет на макросы во всех основных приложениях.

Аудит:

        Включаем логирование запуска процессов и доступа к ФС/реестру. логирование входа в У.З.
